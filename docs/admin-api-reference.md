## auth

| Method | Path | Query | Description |
| --- | --- | --- | --- |
| POST | `/auth/password` |  | Change the admin password. Leaves existing sessions alone - revoking them is a separate, caller-confirmed step. |

| POST | `/auth/session` |  | Log in and create a session. |

| POST | `/auth/two-factor/enrollment` |  | Register a device and hand back its setup key, shown only here. |
| POST | `/auth/two-factor/recovery-codes` |  | Replace the whole set. Any code saved from the previous set stops working. |
